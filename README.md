# 서울 ASOS 풍속 예측 분석

서울 ASOS 108번 관측자료(2023~2024, KST)를 사용해 1시간 뒤 풍속을 예측한 비교 분석입니다.

## Copilot에 요청한 작업

- 원본 CSV의 관측시각 순서, 누락 시각, 중복 시각, 기상요소 빈값 확인
- 1시간 간격으로 정렬한 뒤 현재 풍속·기온·습도와 1·2시간 전 풍속을 입력으로 구성
- 정답은 입력시각 1시간 뒤의 실제 풍속으로 구성
- 정답시각 기준 2023년 1월~2024년 11월을 학습, 2024년 12월을 평가
- 현재 풍속 유지 기준, 선형회귀, 랜덤포레스트를 같은 평가행에서 비교
- 2024-12-01~2024-12-07 KST의 실제값과 예측값을 한 그래프로 시각화

## 직접 확인한 결과

- 원본 데이터 행수: 17,509행
- 시간축 기대 행수: 17,544행
- 누락 관측시각: 35개
- 중복 관측시각: 0개
- 원본 풍속 빈값: 33개
- 원본 기온·습도 빈값: 0개
- 결측 및 입력·정답 빈 행을 제외한 최종 데이터셋: 17,464행
- 학습행: 16,720행
- 2024년 12월 평가행: 744행

## 모델 비교

모든 모델은 동일한 5개 입력과 동일한 학습·평가 기간을 사용했습니다. 음수 예측은 0으로 제한했습니다.

| 방법 | 설정 | 2024년 12월 MAE |
|---|---|---:|
| 현재 풍속 유지 | 현재 풍속을 1시간 뒤에도 유지 | 0.6534946237 m/s |
| 선형회귀 | 5개 입력, 음수 예측 0 처리 | 0.5945766854 m/s |
| 랜덤포레스트 | 100개 나무, 최대 깊이 6, 잎 최소 5, seed 42 | 0.5951519396 m/s |

선형회귀는 기준예측보다 0.0589179383 m/s 낮았고, 랜덤포레스트는 0.0583426840 m/s 낮았습니다. 선형회귀가 랜덤포레스트보다 0.0005752542 m/s 낮은 MAE였습니다.

## 크게 틀린 시각

2024년 12월 전체 평가에서 가장 큰 기준예측 오차는 다음과 같습니다.

| 정답시각(KST) | 실제값 | 기준예측 | 선형회귀 | 랜덤포레스트 |
|---|---:|---:|---:|---:|
| 2024-12-30 12:00 | 3.7 | 0.5 | 0.9480 | 1.0781 |
| 2024-12-18 23:00 | 0.7 | 3.8 | 3.3204 | 3.1849 |
| 2024-12-08 18:00 | 1.7 | 4.2 | 3.6307 | 3.5272 |
| 2024-12-13 22:00 | 2.1 | 4.5 | 3.7219 | 3.4637 |
| 2024-12-26 04:00 | 4.0 | 1.6 | 1.6872 | 1.6380 |

가장 큰 오차는 관측 풍속이 짧은 시간에 급변한 시각에 나타났습니다. 예를 들어 12월 30일 12시는 실제 3.7 m/s인데 기준예측은 직전 풍속 0.5 m/s를 유지해 3.2 m/s 낮게 예측했습니다. 반대로 12월 18일 23시는 실제 0.7 m/s인데 직전 풍속 3.8 m/s를 유지해 3.1 m/s 높게 예측했습니다. 두 경우 모두 현재값 유지 방식이 급격한 변화에 대응하지 못한 사례입니다. 선형회귀와 랜덤포레스트도 변화의 크기를 완전히 따라가지는 못했지만 기준예측보다 오차가 작았습니다.
